# Flintglade

Flintglade is an independent technology company building analytics infrastructure, source-backed research software, market information systems, and applied AI with auditable methods.

Public software is maintained through the [Flintglade Tools organization](https://github.com/flintglade-tools):

- [Proscenium](https://github.com/flintglade-tools/proscenium) — a local-first deterministic webhook reliability lab for Windows.
- [Greenlit Goods](https://github.com/flintglade-tools/greenlit-goods) — an offline Google Merchant Center feed preflight and conservative repair tool.
